FortressGen Help

🔐 Randomness

This generator uses the browser's crypto.getRandomValues() API instead of ordinary Math.random() for password generation.

🧠 Entropy

Entropy is an estimate of how many bits of uncertainty a generated password has based on its length and character pool.

⚠️ Important

Do not reuse the same password across important accounts. A password manager is generally safer than trying to memorize many unique passwords.

⌨ Keyboard

Ctrl/Cmd + Enter generates a password.
